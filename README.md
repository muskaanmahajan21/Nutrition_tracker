🍏 Nuttrify – Nutrition Tracking System
📘Overview

Nuttrify is a fully structured and user-friendly Nutrition Tracking System that helps users log meals, calculate calories, view nutritional breakdowns, and track long-term diet trends. The system especially focuses on Indian plant-based diets and provides personalized insights.

🌐 Live Demo

➡️([View the Live Site Here](https://muskaanmahajan21.github.io/Nutrition_tracker/))⬅️

⭐ Features

Meal Logging: Users can log their daily meals with serving sizes.
Nutritional Analysis: Displays calories, protein, fats, carbs, and more.
Food Search: Search nutritional values for Indian food items.
Goal Setting: Users set calorie & nutrient goals.
Diet History: View past consumption records by date.
Personalized Recommendations: Meal suggestions based on goals.
Secure Authentication: JWT-based login & registration.

⚙️ System Modules

🔐 User Module
Handles registration, login, authentication, and profile data.

🥗 Food Logging Module
Logs user meals, calculates nutrients, and saves history.

🔍 Recommendation Module
Suggests meals based on dietary preferences & goals.

📊 Progress Tracker
Generates charts for daily/weekly/monthly nutritional trends.

🛠️ Admin Module
Ensures system reliability, monitors performance.
